# 音效库（assets/sfx）

> 使用：分镜 sfx 事件 `{"name": "<文件名>", "at": 秒, "vol": 音量}`。
> vol 受全局上限 max_sfx_volume 约束（默认 0.12，克制使用）。
> 所有音效会统一 loudnorm 到 -23 LUFS / 峰值 ≤ -6dB。

## 用户确认的音效（儿童故事适用）

| 文件名 | 听感 | 适用场景 |
|---|---|---|
| `kid_laugh_soft.mp3` | 一个小孩在笑（一般/温和） | **日常温馨笑声**（如"全家都笑了"），首选 |
| `kid_laugh_big.mp3` | 一个小孩笑得厉害 | 需要更明显笑声时（笑得前仰后合） |
| `horn_short.mp3` | 小喇叭/短号声 | **惊讶/出错/被缠住**（如跳绳缠脚），有提示感 |
| `dun_funny.mp3` | "dun"二声，有喜感 | 搞笑/反转/尴尬时刻（缠脚备选） |
| `slide_cartoon.mp3` | 卡通滑落感 | 摔倒/滑倒/溜走 |
| `fart.mp3` | 放屁声 | 恶趣味搞笑（慎用，看故事风格） |
| `realize.mp3` | 上行"叮~叮"（恍然大悟） | **故事收束/明白真相**（如爸爸解释后"原来如此"） |

## 音效使用规范（氛围烘托，不并列）
- **at 用负值**：`at: -0.3` 表示"镜尾前 0.3s"——音效放进句末停顿处，作氛围烘托，不叠在旁白/台词上
- **结尾收束**：故事最后一句后加 `realize`（恍然大悟），避免戛然而止
- 音量克制（vol 0.3~0.4），响度 loudnorm -18 LUFS

## 备选音效（未确认适用性）

| 文件名 | 听感 | 备注 |
|---|---|---|
| `laugh.mp3` | 疑似机械/发动机声 | ❌ 用户否了，勿用 |
| `surprise.mp3` | 惊讶（1.2s） | 可用，但不如 horn_short 有童趣 |
| `applause.mp3` | 掌声（10s） | 太长，需裁剪；颁奖场景可用 |
| `twinkle.mp3` | 闪烁（3.5s） | 星星/魔法氛围 |
| `magic.mp3` | 魔法（7.4s） | 太长需裁剪；变身/魔法场景 |
| `cand_*.mp3` / `cand2_*.mp3` | mixkit 原始下载 | 用户已听过的候选，勿直接用 |
| `kid_laugh.mp3` / `victory.mp3` / `bounce.mp3` / `dong.mp3` | 长曲目 | 需裁剪成短片段再用 |

## 裁剪方法（长音效 → 短片段）

```bash
ffmpeg -y -i assets/sfx/xxx.mp3 -t 2.5 -ss 3 output/tmp/sfx_cut/xxx_cut.mp3
```

## 备注
- 用户偏好：音效**非常克制**，只在关键/有趣处 1-2 个，音量小。
- 笑声要"温和、圆润、不刺耳"，尖锐的笑声不适合温馨家庭故事。
- 下载源：mixkit（https://mixkit.co/free-sound-effects/），直接抓页面里的 assets.mixkit.co 链接。
